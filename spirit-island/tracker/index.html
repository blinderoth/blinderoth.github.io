Sync to GitHub
Saves the campaign to your site's repository. Visitors can view it but not edit.

How to create the token
  1. Open GitHub: new fine-grained token.
  2. Name it "SI tracker" and pick an expiry date (up to one year).
  3. Under Repository access, choose Only select repositories, then blinderoth.github.io.
  4. Under Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it and paste it above. Do this once on each device you edit from.

The token stays in this browser and is never saved in the repo. The campaign file is spirit-island/tracker/data/save.json. Every save is a commit, so the repo history is your backup.
